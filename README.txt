Pages:
- index.html
- about.html
- products.html
- capabilities.html
- certifications.html
- contact.html

All artwork is stored locally in assets/images as SVG files, so the site works offline.
Open index.html in a browser to preview.

To customize:
1. Replace assets/images/logo.svg with your final logo (or edit the existing SVG).
2. Replace the SVG image files with your real product/company photographs if desired.
3. Update email, address, phone and certification details in contact.html/certifications.html.
4. The contact form is currently a front-end demo and does not send email.
